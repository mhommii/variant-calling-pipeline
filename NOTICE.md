# Data and third-party software

## Data

Everything in [`data/`](data) is synthetic, generated by
[`bin/make_test_data.py`](bin/make_test_data.py) from a fixed random seed. No
third-party or human data is included, so the MIT licence in
[`LICENSE`](LICENSE) covers the data along with the code and documentation.

## Software

The pipeline pulls these tools as container images at run time. They are not
redistributed in this repository and keep their own licences:

| Tool | Licence |
|---|---|
| [FastQC](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/) | GPL-3.0 |
| [BWA](https://github.com/lh3/bwa) | GPL-3.0 |
| [samtools](https://github.com/samtools/samtools) | MIT/Expat |
| [bcftools](https://github.com/samtools/bcftools) | MIT/Expat or GPL-3.0 (optional GPL components) |
| [MultiQC](https://github.com/MultiQC/MultiQC) | GPL-3.0 |
| [Nextflow](https://github.com/nextflow-io/nextflow) | Apache-2.0 |

Cite the publications listed in the README when using these tools.
